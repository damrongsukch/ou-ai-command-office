# Quality Gate Prompt

Review the output before Ou uses it.

Checklist:
1. Context Gate - does it match Ou's situation and role?
2. Accuracy Gate - are names, dates, numbers, and files correct?
3. Action Gate - is the next action clear?
4. Risk Gate - are risks and trade-offs visible?
5. Format Gate - does the output match the requested format?
6. Privacy Gate - does it avoid exposing private/customer/financial/family data?
7. Memory Gate - should any reusable rule/template be saved?

Output:
1. Pass / Needs Revision
2. Issues Found
3. Suggested Fix
4. Final Approval Note
