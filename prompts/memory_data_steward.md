# Memory & Data Steward Prompt

Classify where this information or output should be stored.

Use this rule:
- GitHub = code, dashboard, prompt templates, mock data, schema, public-safe examples.
- Google Drive = real customer data, real meeting notes, real proposals, portfolio exports, family/astrology data, and final documents.

Output:
1. Data Type
2. Public-safe or Private
3. Recommended Save Location
4. Naming Convention
5. Should This Be Committed to GitHub?
6. Next Storage Action
